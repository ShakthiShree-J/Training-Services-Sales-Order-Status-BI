# Training Services – Sales & Order Status Analytics

**GitHub Repository:** `Training-Services-Sales-Order-Status-BI`

## Project Overview
Power BI dashboard analyzing training services sales, order status distribution, and regional and course performance.

## Key Focus & Dashboard Features
* **Core KPIs:** Total Revenue, Total Orders, and Total Customers
* **Order Status Tracking:** Breakdown across Completed, Open, and Cancelled orders
* **Interactive Filtering:** Region, Course, and Order Status slicers
* **Performance Breakdown:** Regional and course-level sales distribution
